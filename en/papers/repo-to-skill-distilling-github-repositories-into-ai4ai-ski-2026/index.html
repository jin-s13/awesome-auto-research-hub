Deep Analysis

Innovations

  • Introduces operational knowledge as the missing layer of domain-specific know-how that separates knowing a method from making it work.
  • Presents DisCo, a skill-powered research agent that creates skills and uses them during research.
  • Distills repository knowledge in two complementary forms: task-agnostic condensation of widely used repositories and task-oriented generation of skills for concrete tasks.
  • Produces the AREX-Skill Library, with 5,000+ verified skills distilled from 1,000 widely used ML repositories and organized into 20 areas and 178 capability families.

Methodology

DisCo distills operational knowledge from GitHub repositories into compact, verified skills. Task-agnostic distillation condenses 1,000 widely used ML repositories into the AREX-Skill Library, while task-oriented distillation produces skills needed for concrete tasks. Evaluation compares a skill-equipped research agent against the same agent without skills using a fixed GPT-5.5 backbone, research harness, and downstream execution budget on MLE-bench, PaperBench, FrontierCS, and PassNet.

Key Results

With the GPT-5.5 backbone, research harness, and downstream execution budget held fixed, the skill-equipped agent scores 134.3% higher on MLE-bench, 34.4% higher on PaperBench, 9.2% higher on FrontierCS, and 14.0% higher on PassNet than the same agent without skills. The AREX-Skill Library contains 5,000+ verified skills distilled from 1,000 widely used ML repositories and organized into 20 areas and 178 capability families.
