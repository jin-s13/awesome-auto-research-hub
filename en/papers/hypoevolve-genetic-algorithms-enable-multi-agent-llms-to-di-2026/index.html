Deep Analysis

Innovations

  • HypoEvolve makes agent collaboration explicit through successive updates to a hypothesis population.
  • A generational genetic algorithm coordinates specialized LLM agents that integrate mechanistic arguments, reconsider assumptions, and assess evidence and testability.
  • The framework directly tests how collaboration affects hypothesis quality by specifying how scientific judgments and new proposals reshape the population each generation.
  • Evaluation uses scientifically meaningful drug repurposing hypotheses linked to target-level biological claims.
  • DepMap and Open Targets are adapted into complementary external measures grounded in experimental, genetic, and clinical evidence.

Methodology

HypoEvolve uses a generational genetic algorithm to coordinate specialized LLM agents that integrate mechanistic arguments, reconsider assumptions, and assess evidence and testability, with each generation updating a hypothesis population. It is evaluated on drug repurposing hypotheses across 34 cancer types using adapted DepMap and Open Targets measures, compared against six baselines.

Key Results

Across 34 cancer types, HypoEvolve achieves the highest scores against six baselines on both external measures, with DepMap selectivity reaching 0.171 versus 0.115 for the strongest baseline. Gains over single-pass generation also generalize to held-out cancer types.
