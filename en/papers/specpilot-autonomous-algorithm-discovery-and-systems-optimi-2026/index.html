Innovations

  • Cost model that locates the largest gaps between the current system and its ceiling in each round
  • Parallel agents that explore optimization directions and integrate successful ones
  • Token forcing that checks every output token against stock to detect reward hacking
  • Structured memory that carries validated mechanisms to new rounds and deployments
  • Discovered general lossless 12-bit weight format
  • Discovered tree verification for hybrid recurrent targets

Methodology

SpecPilot uses an autonomous agentic loop in which a cost model locates the largest gaps between the current system and its ceiling, parallel agents explore optimization directions and integrate successful ones, token forcing checks every output token against stock to detect reward hacking, and structured memory carries validated mechanisms to new rounds and deployments. It is evaluated on speculative decoding across four target models, three drafters, two GPU platforms, and five benchmarks, using speedup over autoregressive decoding as the metric and stock speculative decoding systems as the baseline. No training or quality loss is reported.

Key Results

SpecPilot raised the speedup over autoregressive decoding from stock's 4.46x to 10.87x with one request, and from 1.94x to 3.93x with batching, across four target models, three drafters, two GPU platforms, and five benchmarks without training or quality loss.

Limitations

  • It remains unclear whether stock released parallel-drafting systems attain the full speedup that parallel drafting permits.
  • With one request, each step accepts few tokens but reads every target weight, limiting efficiency.
  • With batching, per-request verification work roughly halves the speedup over autoregressive decoding.
  • Speculative decoding optimizations are deployment-specific; no universal optimization fits every serving regime, drafter, target model, and GPU.
