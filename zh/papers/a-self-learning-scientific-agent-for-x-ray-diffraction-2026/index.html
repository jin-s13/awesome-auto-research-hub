深度分析

创新点

  • 提出Gan Jiang，一个用于粉末X射线衍射的自学习科学智能体，无需重新训练语言模型或改变底层物理模型，即可将分析经验转化为可复用、经过验证的可执行技能。
  • 整合了包含XMatcher、XQueryer、XDecomposer和WPEM的衍射分析生态系统，覆盖物相鉴定、多相分解和物理约束的全谱建模。
  • 实现了一个失败诊断与技能修订循环，能够修订技能指令和代码，并在复用前验证修订。
  • 展示了在FullProf、GSAS-II和PyWPEM上相对于专家设计技能的可迁移、工具无关的精修增益。
  • 在DeltaXRDbench上展示了强大的物相鉴定性能，并在无成分输入的MP500、RRUFF和opXRD单相鉴定中取得了大幅准确率提升。

方法

本文介绍了Gan Jiang，一个基于XMatcher、XQueryer、XDecomposer和WPEM引擎构建的粉末X射线衍射自学习智能体。该智能体诊断分析失败、修订技能指令和代码、验证修订，并使用开发数据选择技能，然后冻结这些技能用于留出评估。它在FullProf、GSAS-II和PyWPEM上的精修分数、DeltaXRDbench上的单相和多相鉴定，以及无成分输入的MP500、RRUFF和opXRD上进行了评估。

关键结果

使用开发数据选择并在留出评估前冻结的技能，在FullProf、GSAS-II和PyWPEM上均取得比原始专家设计技能更高的精修分数。在DeltaXRDbench上，Gan Jiang在单相和多相鉴定中领先于所评估的方法；在不提供成分的情况下，它在MP500、RRUFF和opXRD上的单相top-1准确率分别达到96.30%、81.78%和40.83%，而最强比较器分别为58.00%、58.47%和26.45%。
