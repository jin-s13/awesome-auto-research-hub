深度分析

创新点

  • 识别了长时程 LLM 研究智能体的失败模式：重放不断增长的历史、重复彼此的工作，以及在 token 消耗继续时停止实验。
  • 将这些失败追溯到两个设计选择：研究状态存放在哪里，以及由谁决定下一步尝试什么。
  • 提出基于“有状态搜索、无状态智能体”的 Stateless Language Agents (SLAs)，将持久研究状态保存在 harness 中，并为每次调用重建全新且角色特定的上下文。
  • 实现了一个 SLA 框架：无状态 Advisor 读取 harness 汇总的跨搜索方向证据，并将具体实验分配给并行 Worker。
  • 通过长时程评估和消融实验表明，聚焦上下文和显式分配各自都能提升进展与效率，且短评估视界可能误判研究系统。

方法

SLA 框架将持久研究状态（如候选方案和测量结果）保存在 harness 中，而不是保存在智能体对话中。每次调用都会重建全新的角色特定上下文；无状态 Advisor 读取 harness 汇总的跨搜索方向证据，并将具体实验分配给并行 Worker。该方法在软件工程、内核优化和算法设计任务上，以最高达 10 亿 token 的预算与三个近期框架进行比较，并使用共享检查点进行消融实验。

关键结果

SLA 在所有评估任务上都取得了最佳最终结果，并以比最强内核基线少 84% 以上的 token 达到其最终性能。消融实验表明，聚焦上下文和显式分配各自都对进展有贡献，其影响在完整运行中可能叠加，而 Advisor 消耗的 token 不足 0.6%。
