深度分析

创新点

  • 提出了测试时记忆进化（TTME），一种即插即用的测试时适应方法，通过更新外部记忆而非模型权重来工作。
  • TTME将经验蒸馏到外部记忆中，以指导后续发现，而无需在线权重更新。
  • 提出了一种干净的比较协议，在相同的发现框架下仅替换测试时适应方法。

方法

TTME通过蒸馏经验持续更新外部记忆以指导后续发现，不同于执行在线权重更新的测试时训练。TTME和TTT在相同的发现框架下进行评估，仅替换测试时适应方法。评估使用五个数学任务，并报告性能、FLOPs和运行时间。

关键结果

TTME在所有五个数学任务上优于TTT，同时将计算成本降低82.8-84.6%的FLOPs和47.7-58.4%的运行时间。

局限性

  • 摘要未明确说明除所评估的发现设置之外的限制。
  • 结果仅在特定发现框架内的五个数学任务上报告，因此尚未确立更广泛的泛化性。
