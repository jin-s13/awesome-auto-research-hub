深度分析

创新点

  • 提出ParetoRSI-Gym，一个多领域递归自我改进基准，其中智能体搜索数据、筛选数据、训练、读取各领域结果并重复进行。
  • 同时评估五个领域上的数据驱动后训练，使增益与回退之间的权衡明确化。
  • 使用各领域泛化基准，将能力提升与对智能体所优化分数的过拟合区分开。
  • 表明智能体框架与其驱动的模型同样重要，且不同智能体会形成不同的数据选择策略。

方法

ParetoRSI-Gym固定初始LLM、五个领域（数学、代码、金融、医学、科学）、工具集和SFT流水线；智能体搜索并筛选数据、训练、回读各领域结果，并重复进行。每个领域的泛化基准将真实能力提升与过拟合区分开。该设置使用三个智能体系统、三个基础模型、五轮和多个随机种子进行评估。

关键结果

最强系统Claude Code with Opus-5将其代理最优检查点的泛化分数相对于初始模型提升9.2%（+2.3绝对分），在三个基础模型和五个领域上等权平均；在Ministral-3-3B的医学领域上单领域相对增益最高达63%。

局限性

  • 除数据外所有组件均固定，包括初始LLM、领域、工具集和SFT流水线，因此其他递归自我改进组件未被变化。
  • 评估仅限于五个领域、三个智能体系统、三个基础模型和五轮，可能无法推广到其他设置。
  • 报告的泛化增益是针对智能体的代理最优检查点，不一定是最佳泛化性能的检查点。
